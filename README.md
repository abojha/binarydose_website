## 📖 About Binary Dose

**Binary Dose** is a modern, high-signal educational platform designed to help students, software engineers, and technical interview candidates master core Computer Science fundamentals and Data Structures & Algorithms without unnecessary fluff.

From interactive execution visualizers to in-depth Operating Systems internals and scalable System Design breakdowns, Binary Dose delivers practical, battle-tested knowledge built for real-world engineering and top-tier technical interviews.

---

## 🚀 Key Highlights & Modules

### 1. 🧪 AlgoDose (Interactive Algorithm Lab)
- **Live Algorithm Execution**: Real-time visual intuition for complex algorithmic patterns.
- **Synchronized Code Sync**: Watch execution flow line-by-line in Python while state variables, pointers, and memory partitions dynamically update.
- **Supported Engines**:
  - 🔍 **Binary Search**: Exact match search, lower bound, upper bound, rotated search space convergence.
  - ↔️ **Two Pointers**: Opposing pointers (Two Sum), Fast & Slow pointers, three-sum boundary pruning.
  - 🪟 **Sliding Window**: Fixed size max-sum subarrays, dynamic variable-size windows, and substring tracking.
  - 📊 **Sorting Algorithms**: Bubble sort, Selection sort, step-by-step element comparisons, swaps, and sorted boundary partitions.
- **Mobile-First Responsive Design**: Clean 7-box single-row layouts with zero pointer overlap and custom-themed popovers.

### 2. 💻 CodeDose (DSA Mastery)
- Curated patterns categorized by algorithmic paradigm.
- Time & Space Complexity formulas ($O(N)$, $O(\log N)$, $O(1)$) with rigorous Big-O analysis.
- Clean, readable, and production-ready Python & C++ implementations.

### 3. 🎯 100 Days Interview Curriculum
- Structured day-by-day roadmap covering:
  - **Operating Systems**: CPU scheduling, virtual memory, paging, concurrency, deadlocks.
  - **Computer Networks**: TCP 3-way handshakes, sockets, HTTP/3, DNS resolution.
  - **Database & System Design**: Indexing (B+ Trees), caching (Redis), rate-limiting, CAP theorem.

### 4. ✍️ Engineering Blog & Community Ecosystem
- Technical breakdowns authored by engineers, students, and educators.
- Contributor author profiles with backlinks to personal GitHub, LinkedIn, and portfolios.

## 🛠️ Local Development Quickstart

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your system.

```bash
# 1. Clone your fork or the official repository
git clone https://github.com/abojha/binarydose_website.git
cd binarydose_website/binary_dose

# 2. Install dependencies
npm install

# 3. Start local development server
npm start
```

Your local instance will be running live at `http://localhost:3000`. Changes are hot-reloaded automatically.

To create an optimized production build:

```bash
npm run build
```

## 🤝 How to Contribute Articles

We warmly welcome technical contributions from the developer community! If you would like to write an article, interview experience, or problem breakdown:

1. Read our **[CONTRIBUTING.md](CONTRIBUTING.md)** guide.
2. Fork the repository and add your author profile to `blog/authors.yml`.
3. Write your technical post in `blog/YYYY-MM-DD-your-article-slug.md`.
4. Open a Pull Request! Once merged, your article will be published live with full author attribution.
